# QuizKilat 📝
A **responsive and interactive Quiz App** built using **HTML, CSS, and Vanilla JavaScript** — no frameworks required.  
This project was developed as part of a **Udemy course by James Q Quick**, focusing on practical, real-world frontend development.

Users can answer multiple-choice questions, track their progress and score, and save high scores for future sessions.

## 💻 Features
- Fetches trivia questions dynamically from an **external API (Open Trivia DB)**  
- Real-time **score calculation** and result display  
- Stores **high scores** using **localStorage**  
- Fully **responsive design** for mobile and desktop  
- Interactive UI elements including:
  - Progress bar  
  - Answer feedback (correct / incorrect)  
  - Smooth transitions and animations  

## 🛠️ Technologies Used
- **HTML5** – Semantic structure and layout  
- **CSS3** – Flexbox, animations, and responsive design  
- **JavaScript (ES6+)** – DOM manipulation, event handling, Fetch API, and local storage
